Transition Reference
====================

This repository no longer owns production runtime behavior for name generation.

Canonical repositories:

1. ``pipeworks-namegen-lexicon`` for lexicon/corpus pipeline ownership.
2. ``pipeworks-namegen-core`` for deterministic generation primitives.
3. ``pipeworks-namegen-api`` for production runtime and deployment ownership.

Production deployment templates are maintained in:

- ``https://github.com/pipe-works/pipeworks-namegen-api/tree/main/deploy``

This page remains intentionally brief to reduce ambiguity during migration and
archival preparation.
