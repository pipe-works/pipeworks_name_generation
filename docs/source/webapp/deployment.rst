Deployment (Legacy Pointer)
===========================

This repository is no longer the canonical production runtime owner for
name-generation service deployment.

Canonical runtime ownership now lives in:

1. ``pipeworks-namegen-api``
2. ``https://github.com/pipe-works/pipeworks-namegen-api/tree/main/deploy``

Use the API repository deployment artifacts for production:

1. ``deploy/systemd/pipeworks-namegen-api.service.example``
2. ``deploy/nginx/name.api.example.org.conf.example``
3. ``deploy/server.ini.example``

This pointer page is retained for migration continuity only.
